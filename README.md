# Персональная «карта знаний» из рукописного текста

> **Командный проект НИУ ВШЭ — Нижний Новгород**  
> **Статус проекта:**

## О проекте

Веб-сервис на базе искусственного интеллекта, который автоматически превращает учебные материалы (включая рукописные конспекты) в персонализированную карту знаний и интерактивные квизы для эффективного запоминания.

### Зачем это нужно?
Обычное перечитывание конспектов даёт низкий результат: уже через неделю в памяти остаётся около 40% информации. Активное припоминание (квизы и карточки) повышает этот показатель до 61%, а регулярная практика снижает риск провала экзаменов почти в 4 раза. Наш сервис автоматизирует создание таких инструментов прямо из тетрадей и файлов студента.

---
## Ключевые возможности сервиса

### 1. Мультиформатная загрузка и настройка генерации
* **Три способа создания материала:** загрузка файлов (`PDF`, `DOCX`, фото/сканы рукописного текста `JPG`, `PNG`), вставка скопированного текста или генерация по заданной теме.
* **Гибкая настройка квизов:** выбор количества вопросов и уровня сложности (включая режим *«Строго по тексту»* без выхода за рамки конспекта).

### 2. Интеллектуальная обработка и граф знаний
* **Умное извлечение смыслов:** автоматическое распознавание текста, формул, ключевых понятий и логических связей между ними.
* **Персональная карта знаний:** визуализация изученного материала в виде интерактивного графа, где понятия связаны между собой.
* **Адаптивное обучение:** подстройка сложности и частоты повторений под уровень знаний, цели, темп и прошлые ошибки пользователя.

### 3. Четыре режима работы с конспектом
Для каждого конспекта формируется единое рабочее пространство со вкладками:
* **Конспект и карта** — структурированный оцифрованный материал и визуальный граф понятий.
* **Карточки** — интерактивные флеш-карточки (вопрос/ответ) с самопроверкой (*«Знаю»* / *«Не знаю»*).
* **Тесты** — квизы с выбором варианта ответа для проверки усвоения темы.
* **Результаты** — разбор ошибок и оценка прогресса по конкретному набору.

### 4. Личный кабинет и геймификация
* **Библиотека наборов:** хранение всех созданных курсов и конспектов с наглядной шкалой прогресса по каждой теме.
* **Аналитика обучения:** статистика пройденных квизов, затраченного времени, общего процента успеха и истории последних тестов.
* **Ударный режим (Streak):** отслеживание ежедневной серии занятий по дням недели и фиксация личного рекорда для поддержания мотивации.

---

## Планируемые технологии

* **Искусственный интеллект и обработка данных:** OCR / HTR (распознавание рукописного текста), LLM и NLP (Prompt-based learning), Triple Extraction (извлечение связей).
* **Веб-интерфейс и логика:** HTML, CSS, JavaScript, Python (Flask).
* **Хранение данных:** SQL (данные пользователей), Neo4j (хранение графа знаний).
